GenLayer Asimov

An announcement is published only if its own cited source backs it.

Anyone can post an announcement, but it stays unverified until the contract fetches the page it names and a round of GenLayer validators agrees the source supports the claim. Only VERIFIED bulletins are meant to be trusted. A source that contradicts the claim marks it REFUTED; one that cannot be read leaves it PENDING.
